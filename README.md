# VALLIKS — دليل الاستعمال

موقع بيع تيشيرتات أوفرسايز، بالدفع عند الاستلام والطلب عبر واتساب.
عربي (RTL) + فرنسي، بلا سيرفر وبلا اشتراك شهري.

---

## 1. كيفاش تشغلو

```bash
npm install       # مرة وحدة
npm run dev       # http://localhost:5173
```

لباش تشوفو من التيليفون ديالك (نفس الويفي):

```bash
npx vite --host
```

غادي يعطيك رابط بحال `http://192.168.x.x:5173` — حلو ف التيليفون.

**اختبار اللغة بسرعة:** زيد `?lang=ar` ولا `?lang=fr` ف آخر الرابط.
هاد الشي كيخدم حتى ف الموقع الحقيقي — تقدر تصيفط رابط فرنسي لجمهور
فرنكوفوني ف إعلان إنستغرام.

## 2. أهم حاجة: بدل هاد الأرقام قبل ما تنشر

كلشي ف ملف واحد: **`src/data/products.js`**. معلّم بـ`TODO`.

### أ) رقم الواتساب — **بلا هادشي الطلبات ماغاديش توصلك**

```js
export const SHOP = {
  whatsapp: '212600000000',   // ← بدلو
```

الصيغة: كود الدولة + الرقم **بلا الصفر وبلا +**.
مثال: `0612345678` كيولي `212612345678`.

### ب) الأثمنة

```js
{
  id: 'aaargh',
  price: 189,     // الثمن الحالي
  was: 249,       // الثمن قبل التخفيض — حيد هاد السطر إلا ماكانش تخفيض
```

### ج) ثمن التوصيل والمدن

```js
export const CITIES = [
  { ar: 'الدار البيضاء', fr: 'Casablanca', fee: 25 },
```

و`freeShippingAbove: 400` = فوق 400 درهم التوصيل مجاني.

### د) جدول القياسات ← **أهم من كلشي**

```js
export const SIZES = [
  { size: 'S', chest: 54, length: 69, sleeve: 22 },
```

الأرقام اللي حاطين دابا **تقديرات سوق، ماشي قياسات التيشيرتات ديالك**.

خد تيشيرت حقيقي من المخزون، بسطو على الطاولة، وقيس:
- **عرض الصدر**: من تحت الإبط للإبط الآخر
- **الطول**: من أعلى الكتف حتى للحافة السفلية
- **الكم**: من الكتف حتى لطرف الكم

هاد الجدول هو اللي كينقص الإرجاع أكثر من أي حاجة أخرى ف الموقع.
ماتخليهش غالط.

### هـ) إنستغرام / تيكتوك

```js
instagram: 'https://instagram.com/valliks',
tiktok: '',      // خليه فارغ إلا ماعندكش — الأيقونة كتختافى وحدها
```

## 3. كيفاش تبدل ولا تزيد صور

**سميات الملفات ↔ المنتوجات** — كل منتج عندو `id` ف `products.js` ونفسو هو
بداية اسم ملف الصورة:

| المنتج | `id` | ملفات الصور ف `raw/products/` |
|---|---|---|
| TOTAL STRIKE | `total-strike` | `-black.jpg` · `-white.jpg` · `-navy.png` · `-green.png` · `-pink.png` · `-mint.png` |
| HIGH ROLLER | `high-roller` | `-black.jpg` · `-navy.png` · `-green.png` |
| SPEED DEMON | `speed-demon` | `-black.jpg` · `-white.jpg` · `-navy.png` · `-green.png` · `-mint.png` |
| OUTLAW | `outlaw` | `-black.jpg` · `-navy.png` |
| أوفرسايز خاوي | `blank` | `-black.jpg` · `-white.jpg` |

(السميات مختصرة — البادئة هي دائماً الـ`id`. المجموع: **18 ملف**.)

> ⚠ **الـ`.jpg` والـ`.png` ماشي نفس الجودة.** الـ8 ديال `.jpg` هوما موكابات
> **فوتوغرافية** (نسيج، طيات، ظل حقيقي). الـ10 ديال `.png` هوما موكابات
> **فيكتور مسطحة** — بلا نسيج. ملي الزبون يبدل من كحل لأزرق ف نفس المنتج،
> التيشيرت كيولي مسطح فجأة. شوف القسم 5.

1. حط الصورة الجديدة ف `raw/products/` **بنفس السمية القديمة**
   (مثلاً `total-strike-black.jpg`).
2. شغل:

```bash
npm run images
```

السكريبت كياخد **JPG** (موكابات فوتوغرافية بخلفية رمادية) و**PNG بخلفية
شفافة** (موكابات فيكتور). ملي تكون الخلفية شفافة كيستعمل قناة alpha مباشرة
عوض ما يخمن الخلفية — هادشي هو اللي كيمنع الخط الفاتح ف جنب التيشيرت.

السكريبت كيدير أوتوماتيكياً:
- كيبدل الخلفية الرمادية بخلفية الموقع الداكنة، **مع الحفاظ على الظل**
- كيولد نسخة شفافة (للكاروسيل ثلاثي الأبعاد ف الأعلى)
- كيصاوب 3 قياسات WebP (1080 / 720 / 480)
- كيولد صورة مصغرة مموهة كتبان فوراً قبل ما تحمل الصورة

**باش تزيد منتج جديد بالكامل:** زيد الصور ف `raw/products/`، شغل `npm run images`،
ومن بعد زيد الكائن ديالو ف `PRODUCTS` ف `products.js`.

> الكاروسيل مضبوط على **5 منتوجات**. إلا بدلتي العدد،
> بدل `--step: 72deg` ف `src/styles/components/hero.css` لـ `360 ÷ عدد المنتوجات`.

## 3-ب. قسم "صمم ديالك" — كيفاش تزيد رسمة للمعرض

الزبون كيختار تيشيرت خاوي (كحل ولا بيض) + رسمة من المعرض، ولا كيحط الديزاين
ديالو، وكيشوف النتيجة على التيشيرت قبل ما يطلب.

**باش تزيد رسمة:**

1. حط الرسمة **بوحدها** (بلا تيشيرت) بصيغة PNG بخلفية شفافة ف
   `raw/designs/`.
2. شغل:

```bash
npm run designs
```

3. زيد الكائن ديالها ف `DESIGNS` ف **`src/data/designs.js`** (`id` = اسم الملف
   بلا الامتداد).

**جودة الملف**: على الأقل **1500 بيكسل** ف أكبر بُعد. تحت هادشي الموقع كيحذر
الزبون أن الطبعة غادي تبان مبكسلة — ونفس القاعدة كتنطبق على الرسمات ديالك.

> ⚠ الرسمات اللي كاينين دابا ف `raw/designs/` **مستخرجين من الموكابات**
> (760→956 بيكسل)، ماشي الملفات الأصلية. عوضهم بالأصليات بنفس السميات ملي
> تكون عندك — الجودة غادي تكون أحسن للطباعة.

### حجم وموضع الطباعة

الأرقام ف `PRINT` ف `src/data/designs.js` **معايرة على الطبعات الحقيقية ف
الموكابات ديالك** (34→42 سم عرضاً، تبدا من 0.335 من علو الصورة). المعاينة
كتحسب السنتيمتر من `chest` ديال القياس المختار ف `SIZES` — إذن ملي يبدل الزبون
القياس، الطبعة كتكبر معاه بحال ف الواقع.

إلا بدلتي الموكابات الخاوية (`blank-black` / `blank-white`)، **عاود قيس هاد
الأرقام** — هي مربوطة بهاد الصور بالضبط.

### الحد ديال هاد الطريقة

رابط واتساب كيحمل **نص فقط** — ماكيقدرش يلصق صورة. إذن ملي الزبون يحط الديزاين
ديالو، الملف **ماكيتصيفطش**: الرسالة كتجي فيها تذكير بارز باش يلصق الصورة ف
المحادثة بيدو. إلا ولّاو الزبناء كينساو بزاف، الحل هو رفع لخدمة خارجية
(Cloudinary وبحالها) — كيتزاد بعدين بلا ما يتعاود القسم.

## 4. كيفاش تنشر الموقع (مجاناً)

### Vercel

```bash
npx vercel            # أول مرة: كيسولك أسئلة وكينشر نسخة تجريبية
npx vercel --prod     # النشر الحقيقي
```

Vercel كيتعرف على Vite وحدو: `npm run build` والمخرج `dist/`. ماكاين
حتى إعداد خاصك تكتبو.

**⚠ خطوة إجبارية بعد أول نشر.** Vercel غادي يعطيك رابط بحال
`valliks.vercel.app`. دير هادشي:

1. حل `index.html`، قلب على الـ`TODO` ف الميتا (حوالي السطر 24).
2. بدل `https://valliks.ma/` بالرابط الحقيقي ف **`og:url`** و**`og:image`**.
3. `npx vercel --prod` مرة أخرى.

بلا هاد الخطوة، ملي شي حد يصيفط رابط الموقع ف واتساب المعاينة كتبان
**بلا صورة** — النص وحدو. وهادشي كينقص الضغطات بزاف.

### Netlify (بديل)

1. دخل لـ [netlify.com](https://netlify.com) وسجل بحساب.
2. `npm run build`، من بعد سحب مجلد `dist/` وطيحو ف الصفحة.
3. نفس خطوة الـ`og:` فوق، بالرابط اللي عطاك Netlify.

بجوجهم مجاني للمواقع الساكنة وسريع بزاف من المغرب.

### ⚠ ماتحطش المصادر ف `public/`

كلشي اللي ف `public/` كيتنسخ لـ`dist/` وكيولي **محمّل من أي واحد**.
حيت الرسمات ديالك PNG بخلفية شفافة واجدين للطباعة، لو كانو تما أي واحد
كيكتب `موقعك.com/designs/raw/total-strike.png` وكياخدهم.

علاش المصادر ف `raw/` خارج `public/`. النتيجة: `dist/` نزل من 17 MB
لـ**5.5 MB**، والديزاينات ماشي عمومية. `.vercelignore` و`.gitignore`
كيمنعو `raw/` حتى من الرفع.

## 5. شنو ناقص الموقع (بصراحة)

هاد الحوايج ماشي باگات — هي أشياء خاصك أنت تكملها:

1. **ماكاينش شي صورة من الأمام.** كل الـ18 صورة من اللور بلا استثناء.
   الزبون باغي يشوف الوجه ديال التيشيرت.
2. **ماكاينش شي شخص لابس التيشيرت.** صور lifestyle هي أقوى محرك
   للمبيعات ف الستريتوير — أقوى من أي نص ف الموقع.
3. **ماكاينش close-up للطباعة والقماش.** هادي اللي كتثبت أن الطباعة
   ديالك جيدة بصح.
4. **الألوان الجديدة موكابات فيكتور، ماشي تصاور.** الكحل والبيض
   فوتوغرافيين (نسيج + طيات + ظل)، أما navy · green · pink · mint فهوما
   مسطحين. ملي الزبون يكليكي على نقطة اللون كيبان الفرق بالعين، وكيقرا
   منو أن التيشيرت الملون **ماكاينش عندك ف المخزون بصح**. إما تصور الألوان
   الحقيقية، وإلا حيدهم من `products.js` حتى تصورهم.

الموقع مبني بـ**gallery ديال صور متعددة لكل منتج**. منين تصور، غير عوض
الملفات ف `raw/products/` وشغل `npm run images` — ماغاديش نمسو
حتى سطر من الكود.

## 6. هيكل المشروع

```
raw/                ← المصادر ديالك. **ماكيتنشرش** (شوف التحذير تحت)
  products/         الموكابات الأصلية (اللي كتحط أنت)
  designs/          الرسمات بوحدها للمعرض (اللي كتحط أنت)
  brand/            logo-raw.png + نسخ PNG وسيطة للشغل

public/             ← كلشي هنا كيتنشر ويقدر أي واحد يحمّلو
  products/         الصور المعالجة (مولّدة — ماتعدلهاش بيدك)
  designs/          الرسمات المعالجة (مولّدة)
  brand/            favicon.png + 3 ملفات .webp فقط
  fonts/            الخطوط (self-hosted، بلا Google CDN)

src/
  data/products.js  ← كل التعديلات ديالك هنا
  data/designs.js   ← رسمات المعرض + هندسة الطباعة
  i18n/strings.js   ← النصوص بالعربية والفرنسية
  lib/carousel.js   الكاروسيل ثلاثي الأبعاد
  lib/whatsapp.js   بناء رسالة الطلب والتحقق من الرقم
  components/       الشبكة، النافذة، وقسم "صمم ديالك"
  styles/           tokens.css فيه الألوان والخطوط

scripts/
  prep-images.py    معالجة الصور    (npm run images · npm run designs)
  fetch-fonts.mjs   تنزيل الخطوط    (npm run fonts)
```

## 7. حوايج تقنية خاصك تعرفها

- **بلا Three.js ولا أي مكتبة.** الحركة ثلاثية الأبعاد كلها CSS transforms.
  حجم الجافاسكريبت كامل: **~20 KB مضغوط** (منها ~5 KB ديال قسم "صمم ديالك").
  على 4G مغربي هادي الفرق بين موقع كيتحمل وموقع كيتسد.
- **المعاينة ف "صمم ديالك" كسولة**: الموكاب ديال 1080px ماكيتحملش حتى يقرب
  القسم من الشاشة (IntersectionObserver). وملف الزبون **ماكيخرجش من الجهاز
  ديالو** — كيتقرا محلياً وكيتلصق ف canvas وصافي.
- **الخطوط self-hosted.** ماكاينش طلب لـGoogle — أسرع، وكيخدم حتى إلا
  تحجب Google Fonts على شي شبكة.
- **الطلبات كتمشي مباشرة لواتساب.** ماكاينش قاعدة بيانات وماكاينش تكلفة.
  الحد ديال هاد الطريقة: ماكاينش تتبع تلقائي للطلبات. إلا وصلتي لـ**20+
  طلب فاليوم**، حان الوقت باش نزيدو Google Sheets ولا لوحة تحكم.
- **معلومات الزبون كتتسجل ف المتصفح ديالو** (`localStorage`) باش إلا رجع
  يطلب مرة أخرى الفورم يكون معمّر. ماكيتصيفط والو لأي سيرفر.
- **كلشي كيحترم `prefers-reduced-motion`** — الزوار اللي عندهم حساسية
  للحركة كيشوفو الموقع ساكن بلا ما يتكسر شي حاجة.
